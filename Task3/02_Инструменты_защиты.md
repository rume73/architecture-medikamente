# Инструменты защиты данных

## 1. Назначение

Документ перечисляет базовые инструменты защиты, которые нужно добавить в систему «Медикаменте». 
Опирается на целевую архитектуру (`Task2/02_Целевая_архитектура_C4.md`) 
и классификацию (`01_Классификация_данных.md`).

## 2. Инструменты по состояниям данных

### 2.1. Защита данных at rest

| Инструмент | Тип | Что защищает | Как применяется |
|---|---|---|---|
| **Полное шифрование диска (FDE)** | ПО + АО (SED) | Все данные на сервере | Шифрование дисков серверов и ноутбуков, SED где возможно |
| **Шифрование БД (TDE / column-level)** | ПО | PostgreSQL, ClickHouse | AES-256 для полей с `pii`, `phi`, `payment` |
| **Шифрование объектного хранилища** | ПО | Медкарты, сканы | SSE-S3 / SSE-KMS, ключи в Vault |
| **Шифрование файлов (EFS)** | ПО | Отдельные файлы | Для файлов вне объектного хранилища |
| **HSM / KMS** | АО + ПО | Ключи шифрования | HashiCorp Vault + HSM для мастер-ключей |
| **ACL / RBAC на хранилищах** | ПО | Все данные | Права на уровне файлов, таблиц, записей |

### 2.2. Защита данных in transit

| Инструмент | Тип | Что защищает | Как применяется |
|---|---|---|---|
| **TLS 1.3** | ПО | Все каналы | API Gateway, порталы, интеграции |
| **mTLS** | ПО | Сервис-сервис | Внутренние вызовы в Kubernetes |
| **VPN** | ПО | Удалённый доступ сотрудников | Филиалы, удалёнка |
| **SSH** | ПО | Администрирование | Доступ к серверам |
| **Certificate Management** | ПО | Сертификаты | Vault PKI, автопродление |

### 2.3. Защита данных in use

| Инструмент | Тип | Что защищает | Как применяется |
|---|---|---|---|
| **RBAC / ABAC** | ПО | Доступ к данным в приложении | OPA-политики по тегам и контексту |
| **Динамическая маскировка** | ПО | Отображение PII | Кассир видит только последние 4 цифры карты |
| **Минимизация в памяти** | Практика | Объём данных в RAM | Выборка только нужных полей |
| **TEE (Intel SGX)** | АО | Изолированная обработка | Для самых чувствительных операций (по возможности) |
| **Аудит доступа** | ПО | Все обращения | Elastic, журнал действий |
| **DLP** | ПО | Предотвращение утечек | Контроль выгрузок, почты, USB |

## 3. Инструменты по методам защиты

| Метод | Инструмент | Где применяем |
|---|---|---|
| Шифрование | Vault, TDE, SSE-KMS, TLS 1.3 | At rest, in transit |
| Токенизация | Платёжный провайдер + внутренний токен-сервис | Платёжные данные |
| Маскировка | Динамическая (интерфейсы), статическая (тест-среды) | PII, PHI |
| Обфускация | Скремблирование, зануление | Логи, демо-данные |
| Обезличивание | Псевдонимизация, k-анонимность | Аналитический слой |
| Управление ключами | HashiCorp Vault + HSM | Все шифрованные данные |
| Управление доступом | OPA, Keycloak | Все сервисы |
| Тегирование | OpenMetadata / DataHub | Все данные |
| Аудит | Elastic, auditd | Все системы |

## 4. Инструменты по классам данных

| Класс | Обязательные инструменты |
|---|---|
| Особо чувствительные | FDE + TDE + объектное шифрование + mTLS + RBAC/ABAC + TEE (если возможно) + аудит + DLP |
| Конфиденциальные | FDE + TDE + TLS 1.3 + RBAC + динамическая маскировка + аудит |
| Внутренние | FDE + TLS + RBAC + контроль целостности |
| Публичные | TLS + контроль целостности |

## 5. Соответствие целевой архитектуре (Task2)

| Блок Task2 | Инструмент защиты |
|---|---|
| API Gateway | TLS 1.3, валидация контрактов, скрытие PII |
| Identity & Access Service | Keycloak + OPA |
| Consent & Privacy Service | Аудит, каскадное удаление |
| Data Classification & Tagging | OpenMetadata / DataHub |
| Audit & Monitoring | Elastic, Victoria Metrics |
| Encryption & Key Management | Vault + HSM |
| Object Storage | SSE-KMS, ACL, аудит |
| Databases | TDE, RBAC на уровне записей |
| Privacy Layer | Псевдонимизация, k-анонимность |
| Data Lake / ClickHouse | Шифрование, доступ по ролям |

## 6. Выводы

- Инструменты покрывают все три состояния и все классы данных.
- Аппаратные средства (HSM, SED, TEE) дополняют программные и закрывают риски, 
которые ПО не закрывает (защита ключей, защита памяти).
- Инструменты согласованы с целевой архитектурой Task2 — не «список ради списка», а привязка к блокам.
